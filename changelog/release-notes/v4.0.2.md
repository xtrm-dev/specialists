# v4.0.2 — The coordinator tools answer codemode

Package: `@jaggerxtrm/specialists` · Version: `4.0.2` · Previous: `4.0.1` (2026-10-01)

## Summary

4.0.2 makes the eight `specialist_*` coordinator tools reachable from a
**codemode** script, and makes every refusal read as a failure rather than as
an outcome. Requires pi `0.99.x` for the codemode behaviour; the tools work
unchanged on older hosts.

## Added

- **`outputSchema` on all eight coordinator tools** (pi 0.99 tool exposure).
  A tool that declares an output schema resolves to its `structuredContent`
  inside a codemode script instead of to its model-facing text. Before this,
  a script calling `specialist_status({full:true})` received a JSON *string*.
  It now receives the object.
- **A `specialists` tool namespace.** Codemode groups callable tools by
  namespace, so the eight coordinator tools list under one heading instead of
  eight loose entries.

## Changed

- **Refusals are error results.** A refused dispatch (an incomplete or
  ambiguous contract), an unknown activation, and an unknown `message_id` now
  return `isError: true` instead of a successful tool result carrying a
  `status` field. A coordinator model reading only tool success previously saw
  a refusal as an outcome. The structured payload is still delivered, so the
  refusal stays diagnosable — the model sees an error *and* the reason.
- **Peer ranges.** Both bundled pi extensions now declare
  `@earendil-works/pi-coding-agent: ^0.99.0`. The previous ranges (`^0.85.1`,
  `^0.80.0`) excluded the host they run on: a caret on `0.x` pins the minor
  line, so `^0.85.1` does not admit `0.99.1`.

Model-facing tool output is unchanged. One helper builds both channels from
the same object, and a test pins `structuredContent` to
`JSON.parse(content[0].text)`.

## Security

- **The host-read isolation waiver is renewed for 4.0.2** (`unitAI-641h0`,
  operator-approved 2026-10-01, same terms). Specialists still does **not**
  provide filesystem or host-read isolation. Tracked runs, `sp script`,
  `sp serve`, native MCP activations, pipelines, Pi extensions and child
  processes can read anything the runtime OS identity can read. Use Specialists
  only with trusted, single-tenant callers over private or loopback
  authenticated ingress, with minimal mounts and least-privilege credentials.
  Untrusted, public, cross-tenant and multi-tenant deployments are excluded.
  The waiver expires at 4.0.3 or on 2026-11-03, whichever comes first, unless
  a release enforces host-read isolation before then. The release attestation
  receipt does not authorize publication.

## Upgrade

1. Update the package to 4.0.2.
2. No configuration change. The coordinator tools work on any pi host; only
   codemode itself needs pi `0.99.x`.
3. If you use codemode, enable it with `"defaultTools": ["+codemode"]` in
   `~/.pi/agent/settings.json`, or per invocation with
   `pi --tools read,bash,edit,write,codemode`.
4. In Claude Code, run `/reload-plugins` so the specialists MCP server loads
   the new build.
