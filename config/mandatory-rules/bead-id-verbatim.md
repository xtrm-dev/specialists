LEGACY COMPATIBILITY ONLY. This rule exists for explicitly Beads-backed legacy surfaces during XTRM-93 migration. Do not use Beads as durable authority for native Specialist work. When a legacy command genuinely requires a Beads id, copy the id verbatim from authoritative compatibility context or command output; never reconstruct it from memory. Native activations use the pinned Substrate Issue revision and should load issue-ref-verbatim instead.
