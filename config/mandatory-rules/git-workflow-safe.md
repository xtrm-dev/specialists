name: git-workflow-safe
kind: mandatory-rule
---
Work only inside the workspace/branch admitted for this activation. Hold the live Substrate claim before mutation when the runtime requires one. Commit/push only the files authorized by the pinned Issue SCOPE and current integration contract. A commit, push, Specialist settlement, or PASS verdict does not close the Issue; Closure is explicit durable authority performed only by the authorized owner after required validation/evidence.
